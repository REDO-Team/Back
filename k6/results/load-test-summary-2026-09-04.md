# ReDO k6 부하 테스트 결과

## 1. 테스트 개요

- 실행일: 2026-09-04
- 대상 도메인: 리워드, 포인트, 기여도
- 방식: 인증된 단일 테스트 계정으로 도메인별 조회 시나리오 순차 실행
- 페이지 크기: 10
- 요청 간 대기 시간: 0.5초
- 출력 방식: k6 로컬 터미널 요약
- 공통 기준
  - HTTP 오류율 1% 미만
  - check 성공률 99% 초과
  - 응답 시간 p95 500ms 미만
  - 응답 시간 p99 1,000ms 미만

로그인 요청은 setup 단계로 분리했으며 아래 응답 시간과 오류율은
`phase:measurement` 태그가 적용된 도메인 API 요청만 집계한 값이다.

## 4. 결론

- 리워드, 포인트, 기여도 조회 시나리오는 최대 50 VU까지 오류율과 응답 시간 기준을 충족했다.
- 이번 측정 범위에서는 지속적인 지연 증가나 오류율 상승이 나타나지 않았다.
- 측정 근거상 즉시 적용해야 할 애플리케이션 코드 최적화는 확인되지 않았다.

## 5. 측정 범위와 한계

- 단일 테스트 계정을 사용했으므로 다중 사용자별 캐시 분산 효과는 검증하지 않았다.
- stress 프로필은 50 VU에 도달한 직후 감소하며 최대 부하를 장시간 유지하지 않는다.
- Prometheus 출력이 아닌 로컬 출력을 사용해 EC2 CPU, JVM Heap, Redis 및 DB 지표는
  이 결과 문서에 포함하지 않았다.
- 데이터 규모가 증가하거나 예상 동시 사용자가 50명을 넘는 경우 별도의 장시간 부하 테스트가 필요하다.
